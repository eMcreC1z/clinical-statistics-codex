# 02 Descriptive Statistics

## Goals

Describe the study population, data completeness, baseline balance, and endpoint distributions without overstating inferential conclusions.

## Continuous Variables

- Report mean, standard deviation, median, quartiles, minimum, maximum, and missing count as appropriate.
- Use median and quartiles when skewness or outliers are substantial.
- Check units and clinically meaningful ranges before summarizing.

## Categorical Variables

- Report counts, percentages, and missing count.
- Use denominators consistently and state whether percentages exclude missing values.
- Collapse sparse categories only with clinical justification.

## Table 1 Principles

- Summarize baseline variables before outcome follow-up.
- Avoid using significance testing as the only balance assessment.
- For observational studies, include standardized mean differences when comparing exposure groups.

## Data Completeness

Report missingness by variable, group, site, visit, and time point when relevant. For key variables, inspect whether missingness relates to outcome, treatment, exposure, or follow-up duration.
