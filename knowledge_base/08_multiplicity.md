# 08 Multiplicity

## Sources

- Multiple primary endpoints.
- Multiple doses or treatment arms.
- Multiple time points.
- Multiple subgroups.
- Interim analyses.
- Multiple model specifications.

## Strategies

- Fixed hierarchical testing.
- Bonferroni or Holm adjustment.
- Hochberg or Hommel procedures when assumptions fit.
- Gatekeeping families.
- False discovery rate control for exploratory high-dimensional settings.
- Clearly labeled exploratory analyses without confirmatory claims.

## SAP Requirements

- Define endpoint families.
- Specify testing order and alpha allocation.
- State how missing or non-estimable tests affect the hierarchy.
- Separate confirmatory and exploratory analyses.

## Reporting

Report adjusted and unadjusted p values when useful, but keep the inferential claim tied to the planned multiplicity strategy.
