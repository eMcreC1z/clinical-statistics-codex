# 01 Study Design

## Core Questions

- What is the objective: efficacy, safety, association, prediction, diagnosis, prognosis, or description?
- What is the target population and analysis population?
- What are the exposure, intervention, comparator, endpoint, time window, and estimand?
- Is the design randomized, cohort, case-control, cross-sectional, diagnostic, longitudinal, or survival-focused?

## Design Choices

- Randomized trial: define arms, randomization ratio, stratification, blinding, intercurrent events, estimands, and analysis sets.
- Cohort study: define index date, exposure window, follow-up, censoring, and confounding strategy.
- Case-control study: define source population, case definition, control sampling, matching, and odds ratio interpretation.
- Diagnostic study: define reference standard, target condition, threshold strategy, and intended use.
- Real-world study: define data source, eligibility algorithms, covariate lookback, and outcome ascertainment.

## Minimum SAP Elements

- Objective and hypothesis.
- Study population and analysis sets.
- Endpoint definitions.
- Descriptive summaries.
- Primary and secondary analysis models.
- Covariate adjustment.
- Missing data handling.
- Multiplicity strategy.
- Sensitivity and subgroup analyses.

## Common Risks

- Immortal time bias from incorrect index date.
- Post-baseline covariates used as confounders.
- Undefined censoring rules.
- Multiple endpoint tests without a hierarchy.
- Outcome model chosen before endpoint scale is clear.
